# v0.2.9

- Fix duplicated live transcription text and queue audio chunks to prevent dropped chunks when transcription is slower than recording.
- Improve recording stop/cancellation handling and preserve the resampler's final audio samples.
- Fix QNN partial-text updates and preserve text across transcription windows.
- Recognize downloaded custom and imported models when selecting a model.
- Fix onboarding dismissal and preserve shared files through onboarding.
- Make long transcripts scrollable in History and add deletion controls for downloaded models.
- Improve transcription wake-lock and notification cleanup.

This release retains the persistent signing key introduced in v0.2.8, allowing in-place updates from v0.2.8.

The APK is published by GitHub Actions after unit tests, the Android build, and signing-identity verification pass.
