Fixes the History crash when displaying transcripts that are seven days old or older.

### Signing-key change

This release uses a new, persistent signing key. It cannot update v0.2.5 or v0.2.6 in place because those APKs were signed with different keys. Android may report that the package conflicts with the installed app.

Back up or export your transcripts before uninstalling an older version. Uninstalling can erase app data and downloaded models; models may need to be downloaded again. Do not uninstall until you have saved anything you need.

Starting with v0.2.7, GitHub Actions builds and publishes releases automatically using the same signing key stored in GitHub Secrets. Future releases can update v0.2.7 in place as long as this key is retained.

The APK is published only after the full unit test suite and Android build pass.
